# Размещение на 89.19.211.4

Сайт: **https://67.jeshio.ru/**. Прежний адрес **https://89.19.211.4/** сохранён. Игровое соединение: WSS `/ws` на обоих адресах.

Это отдельная установка: `/opt/roma-operation-67`. Здесь находятся готовая игра, единственная серверная зависимость `ws`, переносимый Caddy, конфигурация, сертификаты и журналы. Node.js используется уже установленный, глобальные пакеты и Docker не устанавливаются. Установка добавляет пользователя без входа `roma67` и две службы `roma67-game` / `roma67-https`.

Обычный HTTP остаётся закрыт. Добавляется только правило UFW для TCP 443 на IP 89.19.211.4 с комментарием `roma-operation-67 HTTPS`. Приложение слушает только 127.0.0.1:5179. HTTPS получает и обновляет сертификат поддомена и короткоживущий сертификат IP через Let's Encrypt, проверка идёт по TLS-ALPN на 443. Сертификаты хранятся внутри `data`; существующие настройки nginx, прокси и MediaMTX не меняются.

Начальные ограничения: 4 комнаты / 16 игроков, процесс игры — максимум 512 МБ памяти и 60% одного ядра; HTTPS — 192 МБ и 20%. Это ограничения ресурсов для совместного размещения, а не результат нагрузочного испытания на 16 реальных игроках. Службы запускаются автоматически после перезагрузки.

## Остановить и включить снова

Через SSH:

```sh
sudo systemctl stop roma67-https roma67-game
sudo systemctl start roma67-game roma67-https
```

Остановка освобождает процессор, комнаты завершаются. Файлы и сертификаты сохраняются.

## Полностью удалить игру

```sh
sudo /opt/roma-operation-67/uninstall.sh --remove
```

Команда останавливает игру, выключает автозапуск, удаляет обе службы, добавленное правило HTTPS, пользователя `roma67` и папку игры с сертификатами и журналами. Другие службы и правила не удаляются. Если системные файлы установки были вручную изменены, скрипт остановится перед удалением для проверки. Серверные комнаты хранятся только в памяти; рекорды и настройки в браузерах игроков остаются.

Без `--remove` скрипт только показывает инструкцию. Локальная папка исходников на Mac не удаляется. Для повторного размещения исходники и эти инструкции сохранены в проекте.

## Проверка и обслуживание

```sh
sudo systemctl status roma67-game roma67-https
curl --fail https://89.19.211.4/health
sudo tail -40 /opt/roma-operation-67/logs/https.log
```

Не публикуйте содержимое `data`: там лежат приватные ключи сертификатов. Версия Caddy закреплена на 2.11.4, архив проверен по SHA-256 из официального релиза. Перезапуск игры завершает активные бои.

Для обновления готовые `dist/` и `dist-server/` собираются на Mac и заменяются при остановленной `roma67-game`; `data`, `.managed-by`, `.firewall-created`, пользователь и службы сохраняются. Начальный `install.sh` специально отказывается перезаписывать существующую установку.
